# 06 — Reference Line Formula Pitfall (`formula="constant"` crash)

## The Symptom

Tableau Public crashes or shows error `d2e8da72` / `error-code-id="3538475634"` during `workbook-dom-loader.load-workbook-dom` (`stack-unwind`).

## The Cause

Attempting to inject a constant reference line using:

```xml
<!-- ❌ WRONG: Tableau XML schema rejects formula="constant" with value="..." in this format -->
<reference-line axis-column="..." formula="constant" id="refline0" value="0.0" .../>
```

In Tableau XML, `<reference-line>` requires specific schema properties. Standard analytics reference lines generated by Tableau UI use:

```xml
<!-- ✅ CORRECT: Instant analytics average reference line -->
<reference-line axis-column="[federated...].[measure]" enable-instant-analytics="true"
                formula="average" id="refline0" label="Average" label-type="custom"
                probability="95" scope="per-table"
                value-column="[federated...].[measure]" z-order="1"/>
```

Along with `<style-rule element="refline">`:
```xml
<style-rule element="refline">
  <format attr="fill-above" id="refline0" value="#00000000"/>
  <format attr="fill-below" id="refline0" value="#00000000"/>
  <format attr="line-visibility" id="refline0" value="on"/>
  <format attr="line-pattern-only" id="refline0" value="dashed"/>
  <format attr="stroke-color" id="refline0" value="#d4d4d44b"/>
</style-rule>
```

## Takeaway

- Use `formula="average"` with `value-column` pointing to the quantitative measure on the axis.
- Do not invent non-standard formula values like `formula="constant"` unless matching an exact XML snippet from an existing Tableau export.
